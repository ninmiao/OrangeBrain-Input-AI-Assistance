# 颜表情意图生成

Android 1.3.6 / Windows 1.4.5；提示词 3.1.0，revision 10。

中英文模式均新增一句规则，不限定输入形式：

> 优先识别任意形式的“颜表情＋描述”意图并生成对应 kaomoji，如“颜表情 笑死”或“yanbiaoqing xiaosi”→(„ಡωಡ„)。

仍只返回一个候选，沿用紧凑 JSON 和空 completion，不增加请求或本地触发词白名单。旧 Android Policy 保留自定义规则并自动补上新增句；内置提示词已有该句时不重复追加。

## 验证

- Windows：23 项 JVM 测试通过，包括旧提示词兼容及不重复追加。
- Windows 实际服务调用 OpenRouter / DeepSeek Flash / Wafer，无思考、普通速度：中文“颜表情 笑死”、中文模式 `yanbiaoqing xiaosi`、英文模式相同字母输入均返回 `(„ಡωಡ„)`；“颜表情 伤心”返回 `(╥﹏╥)`；`hello world` 保持原文。五次请求约 0.39–1.46 秒。
- Android 模拟器：四条实际 API 请求覆盖汉字、字母、英文 `kaomoji laughing` 和伤心描述，均返回单个字符颜表情，约 0.31–1.27 秒；此轮还验证了旧 revision 9 包自动补上新规则。
- 去掉示例的早期版本存在返回 emoji 或仅纠错触发词的问题，最终版已按用户要求加回紧凑示例。

颜表情是开放式生成，不要求所有描述匹配固定字符串；上述结果是小样本实测，不保证模型每次都输出同一个表情。Windows 评估工具的 exact-match 分数对没有枚举全部答案的“伤心”项不适用，应检查实际返回内容。
