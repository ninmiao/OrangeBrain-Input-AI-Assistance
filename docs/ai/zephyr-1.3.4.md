# Android 1.3.4：提供商路由移到模型参数

- 连接配置仅编辑 HTTPS API 地址与 Key，不再编辑提供商。
- OpenRouter Policy 的“模型与参数”页新增提供商路由字段和保存按钮；留空自动路由。非 OpenRouter 接口不显示此控件。
- 延续现有 Policy 的 provider 字段，已有 Wafer US 等配置无需迁移，重新保存连接不会覆盖它。
- 保存提供商只更新当前 Policy；验证地址和模型未变化，并复用现有请求参数校验。无须重新验证密钥，也不会触发云端请求。

验证：Android x86_64 debug 与 ARM64 demo 构建通过，APK 核心和提示词资源检查通过；模拟器已覆盖更新，现有模型设置/参数持久化 4 项回归通过。本次没有真实云端调用；S26 未连接，未更新手机。Windows 1.4.2 发布包未变。
