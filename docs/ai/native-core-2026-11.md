# C++ 核心迁移与协议更新

本轮变更和验证结果以根目录 UPDATE_LOG.md 为准。协议细节见 `shared/native-core/README.md`。

- Android 的 Kotlin UI、系统接入、HTTP 和文件适配继续使用；AI 业务协议由 C++17 统一实现。Windows 1.9.0 的设置、网络、凭据和词库适配也已迁入 C++，移除 JVM，见 `windows/app/`。
- 输出为紧凑 JSON 字符串数组；模型思考字段不参与候选解析。
- Preset 功能与模板删除，旧配置字段忽略，Policy 和密钥保留。
- 默认开启前 50 / 后 0 字上下文；测速也使用上下文与当前 Policy 配置。
- 输出 token 软预算默认 256；截断只恢复完整字符串，当前流式版不自动重试；本页其余内容记录迁移时的验证。
- 设置有效修改自动保存，切换 Policy 立即生效；旧请求结果不会覆盖新配置。
- 新的截断数据集独立保存，原生成语料不变。无收费全量语料调用。
