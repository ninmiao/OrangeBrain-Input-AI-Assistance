# Android 1.4.0

字母键盘顶部新增一行 1–0 数字键，字号 16；AI 设置的键盘区域可开关，默认开启，重新打开键盘生效。数字行额外增加约 40 dp 高度，原高度设置继续控制字母区域。

普通文本框中，数字行、数字页和硬件键盘的数字与字母保留在同一组合中，例如 `nihao123test`、`hello 123 world`，回车原样提交。英文模式先显示组合输入，避免数字或字母提前写入宿主；数字专用输入框和密码框维持原输入规则。

OpenRouter 模型参数页自动获取该模型的供应商，并提供选择列表及刷新按钮；可继续手填路由 ID。网络失败不覆盖现有配置。连接与模型入口及 Policy 列表显示供应商。供应商接口仅获取公开元数据，不携带 Key、不发送推理请求，使用 endpoints 的 tag 字段（例如 `wafer/us`）。

本轮在 API 35 x86_64 模拟器验证；ARM64 demo APK 已构建并检查 AI 组件、传输层和提示词资源。本轮不将模拟器结果等同于 S26 真机验收。

验证结果：模拟器 30 项集成回归全部通过，覆盖数字页延后提交、中英文数字组合、编辑和提交、数字行开关与字号，以及既有分词、密码隔离、Policy 和网络超时回归。另有 1 项真实供应商接口测试通过。共享 JVM 核心 39 项测试通过。测试未发送真实模型推理请求。
