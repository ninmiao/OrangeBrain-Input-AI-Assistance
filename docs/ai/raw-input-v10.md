# 顶部原始输入提示 · ai.10

2026-11-07。默认 Rime AI 主题的候选栏上方增加一行原始输入提示，读取当前 Rime rawInputCached，例如 biru，保留原始按键顺序而不使用分词后的拼音。

样式：12 sp 灰色文字，与候选栏相同背景，最小 20 dp 行高，左右 8 dp、上下 2 dp 留白；单行显示，过长时保留末尾。无输入时整行隐藏，选词上屏、清空、切换英文模式、切换输入框或方案时清除。密码框及非文本输入框不显示，不记录按键历史，不增加网络请求。其他自定义主题保持原布局。

ARM64/x86_64 构建通过。模拟器专项测试验证 biru 原始字符串显示与清空隐藏、AI 候选上屏后隐藏、密码框隐藏、中英文候选交互及接口失败后本地输入正常。测试使用假 Key 和本地固定响应，未发送真实云端请求。

S26 与模拟器已覆盖安装 ai.10，专项检查耗时 23.402 秒。截图 raw-input-v10-biru.png 为故意无效凭据的本地降级场景，输入提示保持正常；raw-input-v10.png 为正常候选场景。
