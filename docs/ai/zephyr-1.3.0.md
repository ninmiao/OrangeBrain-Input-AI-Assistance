# Zephyr Input 1.3.0

- AI 候选数量全局可选 1–5 个，默认 3 个；旧配置自动使用默认值。
- 提示词 2.2.0 按意图、拼音匹配及最少键盘修正对候选排序，允许不同合理解释；不强凑低质量结果。
- 旧 Policy 自定义提示词也追加数量/排序约束；应用按请求时的数量截取返回列表，保留服务端排序。
- AI 候选栏左右滑动，边缘渐隐提示；收到新结果回到首项，拖动不会自动上屏。
- 候选数量改变会使旧请求失效。设置样例、快捷测速、批量测速使用同一数量参数。

排序由模型给出，并非经过校准的概率；真实模型仍可能漏选或误判。
