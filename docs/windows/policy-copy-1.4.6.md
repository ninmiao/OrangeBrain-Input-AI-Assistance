# Windows 1.4.6：复制 Policy

Policy 页面新增“Copy policy + Key / 复制 Policy（含 Key）”。点击先保存当前编辑内容，再复制所选 Policy；新副本展示在编辑页，不自动改为当前启用 Policy。

复制包含接口、模型、提供商、思考强度、速度、自定义提示词、模型能力配置和 API Key。使用新 UUID 与独立 DPAPI 凭据文件，密钥不经剪贴板、日志或明文配置；副本仍绑定相同 HTTPS origin。副本命名为“原名称 副本”，重名自动追加编号。

没有 Key 时可正常复制；原凭据损坏或域名不匹配时失败，不产生半成品；最多 32 个 Policy。修改副本 Key 不影响原 Key。

25 项 Windows JVM 测试通过，其中新增两项覆盖完整设置复制、独立加密 Key、域名限制、独立修改与删除、名称去重、无 Key、失败回滚和数量上限；未发送真实 API 请求。
