# Windows 1.5.0

单个 Setup EXE 包含输入服务、x64/x86 TSF、Kotlin 设置、Java 运行时和词库。安装到系统 Program Files 的 Zephyr Input 目录，自动注册输入法；后续运行同系列 Setup 覆盖更新。系统“已安装的应用”提供完整卸载入口，安装目录内也有 unins*.exe（具体编号以系统卸载入口为准）。

更新与卸载只停止 Zephyr 自身进程。安装全过程持有输入服务部署锁，避免旧服务自动重启占用文件；TSF DLL 按内容哈希命名。其他应用持有的旧 DLL 延后至重启删除，重装时取消当前版本 DLL 的待删除记录。用户词库、设置和 Key 默认保留。

OpenRouter 供应商按所选模型自动拉取，使用真实路由 tag，支持下拉选择、手工填写和刷新；Policy 列表显示模型、思考、速度和供应商。OpenAI 不使用供应商设置。

主键盘数字仍用于选词；数字小键盘保持原有混输行为。本次没有增加 Windows 数字行或改变数字选词设置。

Windows JVM 的 26 项测试通过，包括真实公开供应商接口；原生组件 81 项组合输入、2705 项候选高亮边界和 42 项快捷键检查通过。API 推理未在本轮调用；桌面应用的完整兼容性不是这些检查的覆盖范围。

安装器使用 Inno Setup 7.1.1；产品 EXE 暂未代码签名。Windows 11 x64 为本轮验证系统，Windows 10 与 ARM64 尚未验收。
