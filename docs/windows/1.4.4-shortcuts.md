# Windows 1.4.4：可配置语言与繁简快捷键

输入设置提供中英、繁简两个独立下拉框，保存后生效。中英默认单独轻按 Shift（500 ms 内释放），可选左 Shift、右 Shift、Ctrl+Space、Ctrl+Shift+Space 或关闭；繁简默认 Ctrl+Shift+T，可选 Ctrl+Shift+F、Ctrl+Shift+C 或关闭。组合输入、长按 Shift 不触发语言切换。

包含 1.4.3 的候选窗越界崩溃修复。安装后重新打开原有编辑器，以加载新的 TSF 组件。

验证：22 项 Windows JVM 测试、42 项快捷键状态检查、77 项组合输入与 2,705 项高亮范围检查通过；x64/x86 TSF DLL 加载通过。已安装 1.4.4，真实 TSF 输入框验证左右 Shift 单击、中英切换、Shift+A 大写不误切换、Ctrl+Shift+T 繁简切换。设置页改为 Ctrl+Shift+Space 后即时生效，测试完成后恢复默认 Shift / Ctrl+Shift+T。
