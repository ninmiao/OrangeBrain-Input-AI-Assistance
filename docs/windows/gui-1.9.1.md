# Windows 1.9.1 设置窗口验证

日期：2026-11-16。Windows 原生界面专项更新；Android、提示词及模型协议未变。

## 修改

- 标签补全“方案 / Policy”，附加提示词移到独立页。输入、方案、词库使用双栏，默认窗口为 1000×740 逻辑像素并限制在工作区内；小窗口继续保留滚动。
- 修正下拉菜单展开高度误计入内容高度。页面采用子窗口裁剪、批量移动与一次失效重绘，减少滚动中的重复绘制；模型框关闭时滚轮仍滚动页面。
- Win32 文本边界统一 CRLF，词库摘要分别显示四行，不再挤在同一行。
- 右上角固定保存按钮；修改、切换方案、新建、复制、删除和词库开关均保持草稿，点击保存后生效。关闭未保存窗口提供保存、放弃、取消选择。保存后绿色背景渐淡，修改字段短暂高亮。
- 一键测速使用显式复选框，默认勾选最多五个已有方案。每个结果完成即追加，后续失败或取消不会覆盖已有结果。
- 设置 EXE、标题栏及任务栏嵌入现有应用 Logo，沿用 Android 图标像素。

## 验证

- Windows 原生测试与共享协议 CTest 两组通过；原测试覆盖 84 项 Windows 检查、16 项管道检查及 27 项共享格式检查。
- 隔离目录 UI 自测通过：五页默认尺寸无页面滚动、手动保存前文件不变、切换与复制保持草稿、Key 副本仅在保存后写入、勾选三项/取消一项/刷新后保持勾选、保存反馈、换行、图标、小窗口滚动与模型滚轮保护。
- 电脑操作工具实际确认输入、方案、词库和测速页布局；修改方案名时设置文件未变，点击保存后文件更新，字段及底部状态显示短暂绿色高亮。测试只修改隔离配置。
- 实际勾选三家已保存 Policy 后运行：OpenAI `gpt-6.1-terra` 1445 ms，OpenRouter `qwen/qwen3.8-27b` 964 ms，Gemini `gemini-3.8-flash` 达到原有 10 秒总超时。三项全部显示在同一个结果区，失败没有覆盖前两项。样例是包含前后文的长英文，前两家返回完整候选。
- 仅此轮 UI 操作不代表所有 DPI、显示驱动或所有桌面应用均已复测；未声称新的纠错准确率。本轮没有重复执行上一版的整套安装/卸载循环。
