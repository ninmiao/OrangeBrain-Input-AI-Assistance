# Windows 1.4.3：修复长拼音导致前台应用退出

候选窗绘制辅助提示时误用了拼音高亮区间；当拼音长于提示文字时，`wstring::substr` 越界，异常发生在加载 TSF 的前台应用进程内。

修复前，独立 TSF 测试窗口逐键输入 `tianjianfajianhezhongyingwen` 可复现退出，Windows 生成崩溃转储。相同输入经 IPC 测试正常，故服务层通过不能代替界面验证。

绘制和布局现在都从当前文本读取高亮区间，非法区间回退为不高亮；辅助提示不再借用拼音区间。

验证：77 项原生组合输入检查与 2,705 项高亮范围检查通过，覆盖简体、繁体、英文提示，1–300 字符，以及负数、反向、越界区间。

安装后需重新打开正在运行的编辑器或浏览器，使其加载新版 TSF DLL。

实机界面验证：覆盖安装 1.4.3 后，Win32 Edit 与 RichEdit 逐键输入原始复现串正常；简体、繁体、英文候选显示正常，回车提交成功，长英文输入 116 字符后提交成功。x64/x86 DLL 加载与 COM 接口检查通过，打包 JVM 测试通过。未操作用户的 VS Code 文档。
