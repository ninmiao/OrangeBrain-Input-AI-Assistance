# Windows 1.5.1：模型下拉选择与更新

在 Policies / 策略页，模型既可从下拉框选择，也可直接输入完整 ID。点击“Update models / 更新模型列表”使用当前 Policy 的接口和已保存 Key（或刚填入的 Key）请求 GET /models，不发送推理请求。刷新保留当前选择和未完成的手动输入；保存 Policy 后记住列表，下次打开可直接选择。

列表按 Policy 和接口地址隔离。切换 Policy、修改地址或关闭窗口后，旧请求的返回不会覆盖当前页面。刷新失败保留已有列表和模型，显示错误；更换接口域名时不会把旧来源的已保存 Key 发送给新接口。

OpenRouter 的模型思考参数同步自接口返回内容，未知模型保留手工输入能力。供应商列表仍按当前模型单独更新。OpenAI 未提供的参数能力继续使用已有型号规则，不从模型名称猜测新的档位。

验证：Windows 30 项通过，包括 5 项新增交互/缓存回归；1 项可选公网供应商测试未启用。共享核心 39 项通过。新测试覆盖编辑与下拉选择同步、刷新保留输入、保存后重新读取、失败保留、不同来源 Key 隔离及切换 Policy 后忽略旧响应。未在本轮发送真实模型推理请求。

Windows 安装包包含提示词包 3.1.1，支持任意形式的“颜”“表情”或“颜表情”加描述生成颜表情。Android 1.4.0 安装包保持原版本。此版本仅更新设置与 AI 后台，复用已验证的 1.5.0 原生 TSF 组件。
